# License status

Genji Ball: Community Edition does **not** currently have an open-source license.

Genji Ball was built over several years by many people (see [CREDITS.md](CREDITS.md)). We haven't yet received explicit permission from every author to relicense their work, so we are not attaching a license on their behalf. By default, that means the authors keep their rights.

## What you can do

- Read the code, learn from it, and link to it.
- Play and host the game mode in Overwatch. That's what it was published for.
- Fork this repository on GitHub and open pull requests (GitHub's Terms of Service allow this for public repositories).

## What you should ask about first

- Republishing the mode, or a modified version of it, under a different name or as your own.
- Copying significant parts of the code into another project.

If you want to do either of those, ask on the [Discord](https://discord.gg/genjiball).

## Contributions

By opening a pull request, you agree that your contribution may be included and distributed as part of Genji Ball: Community Edition, and that it can be placed under an open-source license later if the project adopts one.

## Future plans

We would like to move to a proper open-source license once the original authors agree. If you are one of the authors listed in CREDITS.md, please get in touch.

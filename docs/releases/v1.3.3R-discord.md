**Genji Ball CE v1.3.3R is out: Ranked is back!**

Get the code from the host tool's "Copy ranked code" (no import code)
Leaderboard: <https://genjiball.us>

v1.3.3 free-for-all, logged for the ranked leaderboard. It plays exactly like v1.3.3 Default.

**How it works**
- Every round counts, with its full finishing order
- The host tool uploads each match when it ends
- A wrong map, preset, add-on or bot shows "UNRANKED: this match won't count" on screen
- Double sens is on: press Ultimate for the high aim sensitivity

**Rank tags**
- The top 10 get a tag with their place and rating: #1 | 2074
- Everyone else in a tier gets its name: Apprentice, Master, Grandmaster, Ascendant, Champion, God
- A top 10 list on the right links the leaderboard
- Hosts get the code with the current tags from the host tool's "Copy ranked code"

**Tourneys**
- Assigned hosts get the tourney code from the host tool's "Copy tourney code", about an hour before the start
- Tournament preset, a fixed number of rounds (Round x / N), every round counts
- Final standings on screen at the end, screenshotted by the host for the results

**For hosts** (70 - Ranked)
- Ranked logging on, plus Enable Workshop Inspector Log File in the Overwatch options
- Turn the tags or the top 10 list off, move or resize the tags
- A ranked debug HUD to check the logging
- Hosting but not playing for real? Turn on AFK in the host tool: your rating stops changing from the next round

Casual free-for-all stays on v1.3.3 (`926FG`), Teams on v1.3.3T (`11M60`).

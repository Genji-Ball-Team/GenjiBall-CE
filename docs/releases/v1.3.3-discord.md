**Genji Ball CE v1.3.3 is out!**

Import code: **`TBD`**

**Default, Tournament and Tournament+ play exactly like v1.3.2.** Everything new is a setting that's off, or at its v1.3.2 value, unless you change it.

**New for hosts** (most need Preset = Custom)
- Ball Feel: speed per deflect, hit radius, turn rates, deflect window and more
- Arena size and bounce pad tuning, and a fix for getting pinned under the Island ledge
- Dash cooldown, knockdown, custom mobility sliders, double sens %
- Countdown, respawn delay and round win pause
- AntiOrbit and basic anti-orbit tuning
- Tracing view angle, red-green colorblind filter, watermark

**Fixed**
- The next round didn't start when everyone died at once
- The ball bounces off the Workshop Chamber floor
- Custom ability cooldowns reset between rounds
- A clear message on unsupported maps
- Colorblind filter, typos, lower server load

Team Deathmatch comes back later as **v1.3.3T**.

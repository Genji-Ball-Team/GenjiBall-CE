The first Community Edition update. **Default, Tournament and Tournament+ play exactly like v1.3.2.** Everything new is a setting that's off, or at its v1.3.2 value, unless you change it. The only exceptions are the bug fixes below.

## Install
**Import code: `TBD`**. In Overwatch, go to Play → Custom Games → Import Code.

Or paste the code yourself:
1. Download **genjiball-v1.3.3.txt** below and copy its contents.
2. In Overwatch: Custom Games → Create → Settings → Import (top right).

## New for hosts
Every new setting defaults to the v1.3.2 value. Most of them only take effect with **Preset = Custom**, because the other presets force their own values. See [docs/hosting.md](https://github.com/Genji-Ball-Team/GenjiBall-CE/blob/main/docs/hosting.md) for every setting.

- **15 - Ball Feel** (new): speed per deflect, hit radius, turn rates, deflect curve, deflect window and lockout, fast ball speed, and a "reliable hit detection" toggle. They only apply with "custom ball feel" on, which only Preset = Custom allows.
- **20 - Arena**: center exclusion size, arena radius, bounce pad strength, distance, range and cooldown, and a "water ledge fix" toggle for players getting pinned under the Workshop Island ledge.
- **30 - Player**: dash cooldown, dash hit knockdown and its cooldown, a **custom** mobility option with move speed, gravity and jump sliders, and "double sens %".
- **40 - Match**: ball spawn countdown, ball respawn delay and round win pause.
- **60 - Competitive**: AntiOrbit speed, timer, min timer and sleep, and radius, speed and timer for tournament mode's basic anti-orbit.
- **80 - Visual**: tracing view angle, and the red-green colorblind filter and watermark, which are now settings instead of being hardcoded off.

## Fixed
- When every player died at once with three or more players in the game, the next round never started. It now does.
- On Workshop Chamber the ball now bounces off the floor, not only the ceiling.
- Custom abilities: cooldowns now reset when a round ends or the final duel starts.
- On a map the mode doesn't support, everyone now sees a message with the list of supported maps, instead of the game breaking silently. Oasis University, King's Row and Blizzard World are gone from the map list, because Overwatch doesn't allow non-Workshop maps with Workshop extensions on.
- The red-green colorblind filter now shows the same target effects as normal mode, in blue and yellow, including the x-ray icon and the "BALL SPAWNING IN" countdown.
- Typos and unclear wording in player-facing text. The Switch Target ability description now explains single and double press.
- Lower server load from the ball speed HUD.

## Not in this version
